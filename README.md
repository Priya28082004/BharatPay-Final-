# BharatPay

BharatPay is a full-stack digital payment web application inspired by platforms like Google Pay. This project focuses on providing a simple, secure, and user-friendly online payment experience through a modern web interface.

## 🚀 Features

* User authentication system
* Send & receive money functionality
* Secure backend integration
* Responsive payment dashboard
* Transaction management
* Clean and interactive UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* MongoDB

## 📂 Project Structure

* `index.html` → Main frontend page
* `style.css` → Styling and responsive design
* `app.js` → Frontend functionality
* `server.js` → Backend server and APIs
* `test_db.js` → Database testing and connection setup

## 🎯 Objective

The main goal of BharatPay is to learn and implement real-world fintech application concepts by creating a payment platform similar to Google Pay using full-stack web development technologies.

## 💡 Future Improvements

* QR code payments
* UPI integration
* Real-time transaction updates
* Mobile app version
* Enhanced security features
